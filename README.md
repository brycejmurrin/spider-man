# Web-Slinger

An unofficial Spider-Man-inspired open-city fan game for the browser. Pure WebGL2,
no build step, no frameworks — the engine is ported from the Apex 26 project
(same author): HDR post pipeline, procedural neon city, instanced scenery,
tunable third-person cameras.

Swing through a night city on physically simulated weblines: hold to swing,
release to fly, zip to keep altitude, run up walls, land on rooftops.

```sh
npx serve -l 3456 .        # or: python3 -m http.server 3456
```
